# Spotify Clone 🎵

A responsive, feature-rich web music player built with **React.js** and **Tailwind CSS** that replicates the core UI, layout, and playback features of Spotify.

---

## ✨ Features

- **Interactive Audio Playback:** Full audio player integration supporting Play, Pause, Next Track, Previous Track, and Volume adjustment.
- **Dynamic Track Progress:** Real-time seek bar/progress synchronization powered by native HTML5 Audio APIs.
- **Dynamic State Management:** Seamlessly update song metadata, album artwork, and artist names without page reloads.
- **Responsive Dark Theme:** Styled after Spotify's signature dark UI, fully optimized across desktop, tablet, and mobile displays.
- **Modular Component Architecture:** Reusable React components structured for Sidebar, Header Navigation, Main Dashboard, and Bottom Audio Controls.

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite / CRA), JavaScript (ES6+)
- **Styling:** Tailwind CSS / CSS Modules
- **State & Audio:** React Hooks (`useState`, `useEffect`, `useRef`), HTML5 Audio API
- **Icons:** Lucide React / React Icons
